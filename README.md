# 💰 Finance Manager

**Finance Manager** — это полнофункциональное веб-приложение для управления личными финансами и личным малом бизнесом. Оно предоставляет пользователю возможность отслеживать доходы и расходы, анализировать финансовые данные и управлять бюджетом с помощью интуитивно понятного интерфейса.

## 🚀 Демо

Приложение доступно по адресу: [finance-manager-three-lake.vercel.app](https://finance-manager-three-lake.vercel.app)

## ✅ Пользовательские возможности

- 🔄 Добавление, редактирование и удаление транзакций  
- 🗂 Категоризация доходов и расходов  
- 📊 Визуализация данных с помощью таблиц и графиков  
- 📅 Создание финансовых планов  
- 🏦 Отслеживание своих активов (наличные, банковские счета и т.д.)

## 🛠 Технические возможности

- 🧾 Валидация форм через `React Hook Form`  
- ❗ Обработка ошибок и отображение уведомлений  
- 🌐 Интеграция с внешними API (например, курсы валют)  
- 🔢 Форматирование больших чисел (например, `1000` → `1 тыс`, `120000.5` → `120.5 тыс`)  
- 🔔 Уведомления через `react-hot-toast`  
- ⏳ Обработка загрузок и пустых состояний с лоадерами
- 💬 Подсказки (tooltips) для улучшения UX

## 📦 Установка и запуск

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/Sorbon-Sh/Finance-manager.git
   cd Finance-manager
   ```

2. Установите зависимости:

   ```bash
   pnpm install
   ```

3. Запустите серверную часть:

   ```bash
   pnpm run server
   ```

4. Запустите клиентскую часть:

   ```bash
   pnpm run dev
   ```
